Good morning everyone, thanks for joining the planning call. Today I want to walk through the release plan for the dictation app, starting with the parts that are already merged and then the measurements we still owe ourselves. The first item is the recording pill above the dock, which shows the microphone level while the key is held. Several people said that a dead or wrong microphone used to be invisible until the transcript came back empty, so this should save a few confused minutes every week. The second item is the set of voice commands. Saying enter or send it on its own presses return, and a line break phrase inside a sentence now splits the dictation into separate runs that are cleaned one by one, so the language model never sees a break phrase or a newline character. The third item is the per app rules, where a chat application can drop the trailing period and a terminal can skip cleanup entirely. Then we have snippets, which expand a short spoken trigger into a block of text after cleanup, so an address or a repository link no longer has to be typed by hand. After the demo I would like to agree on who records the Spanish test clips, when we run the long form fixtures through the speech model, and whether the hands free latch mode is worth shipping in this cycle or should wait for the next one. Please keep questions for the end, and remember to mute when you are not speaking.
